NVIDIA DGX Cloud / NVIDIA NIM Cloud Infrastructure

Description: GPU inference infrastructure (NVIDIA NIM APIs) for all AI/ML models offered on Phonos

Provider: NVIDIA Corporation

Purpose: Runs inference for all AI/ML models on Phonos. Inputs submitted to a model (sequences, structures, ligands, parameters) are transmitted to NVIDIA NIM for processing; results are returned to and stored on our server in Germany.

Research Preview: NVIDIA's hosted models are used only during the Research Preview, for testing; NVIDIA provides this API for testing and evaluation. Paid plans run the models on machines operated by FyreFly Systems. MolMIM is available in the Research Preview for testing only (see MolMIM above).

Website: https://www.nvidia.com/en-us/data-center/dgx-cloud/
